# docs/plans/

Copied, renamed records of past Claude Code plan-mode sessions for this
repo — from the initial ticket-driven pipeline build through every later
bug fix, feature request, and response to partner feedback.

Kept here, under a descriptive name, instead of only in the global
`~/.claude/plans/` (opaque codename filenames with no link back to a repo).

Named `YYYY-MM-DD-title.md`, one file per plan-mode session, including the
originating Jira ticket key in the title when there is one (e.g.
`2026-07-31-hdxpipe-100-ctrees-initial-build.md`). Copied once
approved/implemented rather than moved — the harness keeps its own copy
under `~/.claude/plans/` independently.

Settled architecture/design decisions get a distilled, durable copy in
`../decisions/` (see `../decisions/README.md`) — this folder stays the full
plan narrative (including partner feedback text and any draft reply);
`decisions/` is what to check first for *why* something is built the way
it is.
